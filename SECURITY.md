# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | ✅ Yes              |
| < 1.0   | ❌ No               |

## Reporting a Vulnerability

**Please do NOT open a public GitHub issue for security vulnerabilities.**

If you discover a security issue, please report it **privately** by emailing:

📧 **security@ultrafaiba.net**

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

We will acknowledge your report within **48 hours** and provide a fix within **7 days** for critical issues.

We follow responsible disclosure — we will publicly credit you in the release notes (unless you prefer anonymity).

## Scope

The following are **in scope** for security reports:
- Authentication bypass in the billing portal
- M-Pesa Daraja API key exposure
- XSS vulnerabilities in the hotspot portal
- MikroTik script injection via the config generator

## Out of Scope

- Issues in third-party libraries (report to them directly)
- Social engineering attacks
- Physical security
